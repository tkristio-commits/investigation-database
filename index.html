Overview

How these codes were assigned

Method

Each free-text factor was read against the CICTT three-tier structure and assigned the single best-fit domain → discipline → element. The existing Identification column (Human / Technical / Environment / Facility) was used as a cross-check, not as the answer.

The taxonomy is written for air-traffic events; its human, organizational, equipment and environment branches were applied to flight-crew and maintenance actions by analogy.

Conventions

“Continued an unstabilised approach / did not go around” → Psychological · Information Processing / Decision Making (the taxonomy lists the go-around decision here).

Hands-on handling and SOP non-compliance → Procedural/Task Performance · Action/Inaction; CRM, briefings and controller–pilot exchange → Coordination.

Component and structural failures → Equipment · Aircraft Systems; navaid and MSAW/radar gaps → Air Navigation Service Provider Systems.

For the Organizational domain the taxonomy has no separate element tier, so the discipline name is repeated in the Element column.

Review notes

Rows sharing the same date / year, operator and aircraft / occurrence belong to one investigation and are banded together — each event takes one of two alternating background tints (cool / warm) with a matching coloured left rail, so consecutive events never share a colour. The event count (here and in the Overview) is the number of distinct investigations in view.

One accident (API Banyuwangi, Cessna C172, Abnormal Runway Contact, 14 Jun 2024) has its two factor rows separated in the source workbook (rows 362 and 365), so it shows as two bands but counts once.

11 factors are marked Undetermined — short-form reports or “NIL” entries with no analysable text.

Rows with two genuine causal threads (for example a weather decision plus a system failure) were coded to the dominant one. These are the rows most worth a second opinion — sort by domain and scan the borderline calls.

A backup of the workbook was saved before columns N–P were written.
